# 11+ Quest 🎮

**Making 11+ exam prep actually FUN.**

## The Problem

Every 11+ prep site is the same: boring practice papers, stressful mock exams, clinical progress tracking. Kids hate it. Parents stress. Everyone suffers.

## The Solution

**11+ Quest** turns exam prep into an adventure:
- 🎮 Gamified learning (level up your character!)
- 🧩 Math mysteries & detective cases
- 😂 Grammar memes that kids actually share
- 🏆 Daily challenges with real rewards
- 👥 Character guides (Professor Numbers, Captain Comma)
- 📱 Works on any device

## Tech Stack

- **Framework:** Astro (fast, SEO-friendly)
- **Hosting:** Netlify
- **Styling:** Tailwind CSS
- **Interactive:** React/Svelte components
- **Content:** Markdown + MDX
